# Проект: Поиск изображений по текстовому описанию

## Описание проекта

Разработана демонстрационная система, определяющая релевантность пары *текст — изображение*. Задача — создать модель, которая получает векторные представления изображений и текстов и выдаёт значение от 0 до 1, отражающее степень соответствия.

Решение может применяться в системах рекомендаций, контентных поисковых движках и мультимодальных продуктах.

## Постановка задачи

- Обучить модель, которая оценивает релевантность текста и изображения.
- Использовать метки, полученные от краудсорсеров и экспертов, как основу для таргета.
- Выстроить пайплайн получения эмбеддингов для изображений и текста.
- Протестировать модель на паре `текст — изображение` из тестовой выборки.

## Описание данных

Проект использует следующие файлы:

- **`train_dataset.csv`** — содержит пары `image_id`, `text_id`, `text`, до 5 описаний на изображение.
- **`CrowdAnnotations.tsv`** — краудсорсинговые оценки релевантности (0–1), число подтверждений и опровержений.
- **`ea.tsv`** — оценки экспертов по шкале от 1 (несоответствие) до 4 (полное соответствие).
- **`test_queries.csv`** — тестовые пары `query_id`, `text`, `rel_img`.
- **`train_images/`, `test_images/`** — изображения.

## Как решалась задача

- Выполнена загрузка и анализ полученных данных.
- Произеведена нормировка целевой переменной и аггрегация оценок с приритетом на мнение экспертов
- Собран единый датасет для обучения будущих моделей.
- Сформирован словарь «юридически чувствительных» терминов.  
- Отфильтрованы все записи, содержащие такие слова, чтобы избежать правовых рисков.
- Произведена веторизация данных:
  **Изображения**: извлечение признаков через **ResNet50** (предобученная модель).  
  **Тексты**: эмбеддинги на основе **BERT**.
-  Все батчи были объеденены в единый массив эмбеддингов, готовый к передаче в модель.
- Обучены несколько моделей машинного обучения и получены следующие метрики:
**Линейная регрессия** — RMSE = 0.21  
**CatBoost** — RMSE = 0.20  
**Полносвязная нейросеть** — RMSE = 0.198  
В качестве основной модели была выбрана полносвязная нейросеть
- В результате тестирования было установлено, что модель корректно определяет общие детали соответствия, но теряет локальные нюансы.  Необходима доработка разметки и увеличение выборки для снижения ошибки и повышения детализации предсказаний.


- Рекомендации и дальнейшие шагиЖ

   - Привлечь дополнительных экспертов.  
   - Ввести более гранулированные категории соответствия.  
2. **Увеличить объём данных**  
   - Собрать больше примеров как «корректных», так и «несоответствующих» пар.

   - Интеграция в MVP-приложение для сбора фидбэка от конечных пользователей.
